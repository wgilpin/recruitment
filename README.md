# recruitment
React / PHP site for recruitment of new members in the game Eve Online

# Prequisites
You'll need `npm`, `yarn` and `php`

Install npm & yarn on a mac: <pre><code>brew install yarn</code></pre>

### Other platforms
[Install npm on other platforms](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)

[Install yarn on other platforms](https://yarnpkg.com/lang/en/docs/install/)

### PHP Install

[How to install PHP](http://php.net/manual/en/install.php)

# Installation

<pre><code>git clone https://github.com/wgilpin/recruitment.git
cd recruitment/testfiles
yarn start
</code></pre>
